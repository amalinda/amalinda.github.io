LoRa IQ Modulator

A tool for anyone to generate the I/Q samples of a LoRa frame, and to add PHY impairments if you want them. Figure 1 shows what a LoRa frame looks like; you can set most of its parts below. Then download the frame in a common format and transmit it with GNU Radio or your favourite SDR. It is a standard LoRa frame, so a commercial off-the-shelf (COTS) LoRa radio will also receive it.

You may also open the file using the IQ Demodulator tool and visualise a detailed view of the frame you generated, demodulated and decoded step by step.

Summary

PHY impairments none

Add PHY impairments as needed: the radios' carrier and clock offsets (CFO, SFO), a sampling time offset (STO), and noise. With none ticked, the file is the ideal signal.

Carrier frequency offset (CFO)How far the LoRa frame is shifted off the channel frequency, as when the two radios' crystals disagree (20 ppm at 868 MHz is about 17 kHz).
Hz
Sampling frequency offset (SFO)The transmitter's clock runs this many ppm faster than the receiver's (negative for slower), so the timing drifts over the frame.
ppm
Sampling time offset (STO)The frame starts this many samples late, so its chirps fall between the receiver's samples (0.5 = halfway between two samples). The shift is the same for the whole frame; a drift that grows over the frame is SFO.
samples
Anticipated SNRAdds the right amount of noise to the generated LoRa frame, so its SNR drops to this value you set. Noise itself comes in many kinds; for now, two are supported:
SNR dB
Noise seed: the same seed gives the same noise

Download

MHz, written into the SigMF description

The download is the I/Q samples alone. SigMF adds a small text file that records the sample rate, format and LoRa settings, for tools that read SigMF; the samples are the same.

How to use this file

  
Interleaved I/Q, little-endian, with no header. cf32 is GNU Radio's complex type. The integer formats are scaled so
     the packet peaks at 95% of full scale (lower with noise, so nothing clips).

  
    
    
  • GNU Radio: File Source (type complex) → your SDR sink, at the sample rate above.
    • 
    
  • USRP (UHD): tx_samples_from_file --file lora.cf32 --type float --rate 1e6 --freq 868.1e6
    • 
    
  • HackRF (ci8, at least 2 MS/s): hackrf_transfer -t lora.ci8 -s 2000000 -f 868100000 -x 20
    • 
    
  • bladeRF (sc16q11): in bladeRF-cli, tx config file=lora.sc16q11 format=bin, then tx start
    • 
    
  • Check it: drop the file into the IQ Demodulator.
